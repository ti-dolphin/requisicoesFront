# Controle DSE — Frontend

Interface web do Controle DSE para requisições e cotações, patrimônio, oportunidades comerciais, apontamentos, ordens de compra e administração.

## Tecnologias

React 18, TypeScript, Vite, Material UI, Redux Toolkit, React Router e Axios.

## Documentação

- [Arquitetura](docs/architecture.md)
- [Módulos](docs/modules.md)
- [Desenvolvimento](docs/development.md)

## Início rápido

```powershell
npm ci
npm run dev
```

O cliente principal acessa `http://localhost:3001` em desenvolvimento.

| Comando | Finalidade |
| --- | --- |
| `npm run dev` | Inicia o Vite em desenvolvimento |
| `npm run build` | Verifica os tipos e gera o build |
| `npm run preview` | Serve localmente o build gerado |

O projeto ainda não possui testes automatizados configurados.
