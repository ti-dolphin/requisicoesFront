# Instruções do frontend

- Leia `README.md` e a documentação relevante em `docs/` antes de modificar o projeto.
- Consulte `docs/architecture.md` antes de alterar estado global, roteamento, autenticação ou clientes HTTP.
- Consulte `docs/modules.md` para localizar implementações no domínio correto.
- Consulte `docs/development.md` antes de executar ou validar o projeto.
- Mantenha components focados em interface, services em comunicação e hooks em comportamento reutilizável.
- Não reproduza no frontend regras centrais que devem ser garantidas pelo backend.
- Execute `npm run build` após alterações de código, quando o ambiente permitir.
- Atualize a documentação quando arquitetura, módulos, configuração ou comandos mudarem.
